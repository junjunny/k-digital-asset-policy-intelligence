# 네이버 공개 기능과 K-DARI의 비교 범위

네이버의 2025-06-12 [공식 검색 전략 자료](https://www.navercorp.com/media/pressReleasesDetail?seq=32581)는 AI 브리핑, 금융·헬스케어 등 주제 확대, 버티컬 에이전트에서 통합 에이전트로의 확장 계획을 설명한다. CLOVA Studio의 공식 [스킬](https://guide-gov.ncloud-docs.com/docs/clovastudio-skill) 문서는 질문과 API 명세를 분석해 적절한 스킬을 선택하는 기능을, [스킬셋](https://guide-gov.ncloud-docs.com/docs/clovastudio-skillset)은 특정 분야에 필요한 여러 스킬 묶음을 설명한다.

그러므로 도메인 특화 검색·스킬·근거 연결이라는 일반 개념이 네이버에 없다고 주장할 수 없다. K-DARI의 검증 대상은 12개 디지털자산 연구 방법론, 법적 상태·기술 구현 구분, 주장 단위 근거 추적, 호환 에이전트 설치 패키지와 통제 실험의 결합이다. 네이버 내부에 동일 구현이 있는지는 `UNKNOWN`이며, K-DARI를 네이버 검색에 직접 설치할 수 있다고 주장하지 않는다.

외부 E군은 A–D 120개와 합산하지 않는다. 모델, 검색 환경, 실행 시점, UI, 내부 지침이 달라 인과 비교가 불가능하다. USDC·Chainlink·Upbit·토큰증권의 네이버 답변은 확보하지 않았고 생성하지 않았다. 사용자가 추후 원본 질문, 제품명, 실행 시각, 캡처, 표시 URL 전체를 제공하면 별도 인간 검토한다.
