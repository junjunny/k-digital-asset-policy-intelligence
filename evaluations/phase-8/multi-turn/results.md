# Multi-turn Results

독립 사용성 에이전트가 세 시나리오를 실제 연속 대화 형태로 작성·평가했다. 상세 원문은 `../usability/skill-evaluation-before-fix.md`에 보존한다.

| 시나리오 | 확인 결과 | 판정 |
|---|---|---|
| CLARITY → “한국에서는?” → “핵심 차이 표” | 같은 법안과 비교 범위를 유지하고 표 형식으로 깊이만 축소 | 통과 |
| “이 코인” → LINK → 실제 사용 → 위험 | 첫 턴에 최소 식별정보를 묻고 LINK 확인 뒤 대상을 재질문하지 않음 | 통과 |
| Ethereum → Solana 비교 → 쉽게 설명 | 기존 네트워크 평가축을 유지하고 마지막 턴에서 표현만 단순화 | 통과 |

독립 에이전트의 답변은 대화 문맥 활용 가능성을 확인한 것이며, 별도 상태 저장 서버나 자동화된 다중 턴 E2E 러너를 구현한 것은 아니다. 이 한계를 문서와 인간 검토표에 유지한다.
