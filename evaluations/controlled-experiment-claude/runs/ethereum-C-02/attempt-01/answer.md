# 이더리움(Ethereum) 네트워크 개요

이 답변은 일반 개념 설명(STANDARD)입니다. 이 세션에서는 웹으로 최신 상태를 검증하지 않았습니다. 업그레이드 일정과 수치는 학습 지식 기준이며, 공식 자료로 확인한 사실이 아닙니다.

## 1. 한 줄 정의
이더리움은 전 세계 수천 개 노드가 같은 상태(계정 잔액, 스마트 컨트랙트 코드와 데이터)를 공유하는 **프로그래밍 가능한 퍼블릭 블록체인**입니다. 네이티브 자산은 **ETH**입니다. 비트코인이 주로 "가치 이전"에 쓰인다면, 이더리움은 **스마트 컨트랙트 실행**을 핵심으로 합니다.

## 2. 핵심 구성요소
| 구성요소 | 설명 |
|---|---|
| **EVM** (Ethereum Virtual Machine) | 스마트 컨트랙트를 실행하는 가상 머신입니다. 솔리디티 같은 언어로 작성한 코드가 여기서 돌아갑니다. |
| **계정 모델** | 개인 키로 제어하는 외부 소유 계정(EOA)과 코드가 있는 컨트랙트 계정이 있습니다. |
| **가스(Gas)** | 연산량에 비례하는 수수료입니다. 스팸과 무한 루프를 막고 자원 사용에 값을 매깁니다. |
| **EIP-1559** | 2021년부터 수수료를 기본 수수료(base fee, 소각)와 팁으로 나눕니다. |

## 3. 합의 방식: 지분증명(PoS)
- 2022년 9월 **The Merge**로 작업증명(PoW)에서 지분증명(PoS)으로 전환했습니다. 전환 후 에너지 소비가 대폭 줄었습니다.
- **검증자(validator)**는 ETH를 예치(스테이킹)합니다. 기본 단위는 32 ETH이고, 이후 업그레이드로 한도가 확대되었습니다.
- 규칙 위반 시 예치금이 삭감(슬래싱)될 수 있습니다.
- 구조는 **실행 계층**(EL, 트랜잭션과 EVM)과 **합의 계층**(CL, 블록 확정)으로 나뉩니다. 각 계층에 여러 클라이언트 구현이 있어 단일 소프트웨어 버그의 위험을 분산합니다.

## 4. 확장성 전략: 롤업 중심 로드맵
이더리움 기본 계층(L1)은 처리량이 제한적입니다. 그래서 **L2 롤업**(Optimism, Arbitrum, Base, zkSync 등)이 거래를 모아 처리하고, 결과를 L1에 기록해 보안을 상속받는 구조를 택합니다.
- **EIP-4844(Dencun, 2024)**: "블롭" 데이터를 도입해 L2 비용을 크게 낮췄습니다.
- 이후 업그레이드(Pectra, Fusaka 등)로 블롭 용량 확대, 계정 추상화 개선, 스테이킹 한도 조정 등이 진행되었거나 진행 중입니다. 정확한 적용 상태는 공식 자료 확인이 필요합니다.

## 5. 생태계에서 하는 역할
- **DeFi**: 탈중앙화 거래소, 대출, 파생상품
- **NFT**와 디지털 소유권
- **스테이블코인**: USDT, USDC 등 상당수가 이더리움과 L2에서 발행됩니다.
- **실물자산 토큰화(RWA)**: 많은 사례가 이더리움 계열에서 진행됩니다.
- **DAO** 등 온체인 거버넌스

## 6. 주요 위험과 한계
- **수수료 변동성**: 혼잡 시 L1 수수료가 급등합니다.
- **스마트 컨트랙트 위험**: 코드 버그와 해킹이 있었습니다(2016 The DAO 사건이 대표적입니다).
- **L2 분절화**: 유동성과 사용자 경험이 쪼개지고, 일부 L2는 시퀀서 중앙화와 업그레이드 권한 문제가 있습니다.
- **스테이킹 집중도**: 리퀴드 스테이킹 프로토콜과 대형 사업자 비중이 커서 탈중앙화 논쟁이 있습니다.
- **MEV**(최대 추출 가능 가치)와 검열 저항성 문제
- **규제 불확실성**: 스테이킹, 토큰의 증권성 등은 관할권마다 다릅니다.

## 7. 비트코인과의 차이
| | 비트코인 | 이더리움 |
|---|---|---|
| 주된 용도 | 가치 저장, 송금 | 스마트 컨트랙트 플랫폼 |
| 합의 | PoW | PoS |
| 프로그래밍 | 제한적 | 튜링 완전 (EVM) |
| 공급 | 상한 고정 | 상한 없음, 소각과 발행으로 변동 |
