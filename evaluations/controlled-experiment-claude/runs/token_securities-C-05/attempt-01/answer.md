토큰증권(STO)으로 금융기관은 **발행·유통·보관·운용 단계마다 수수료를 받고, 자기자본으로 직접 투자해 수익을 내는 방식**으로 돈을 법니다. 아래는 일반적인 사업모델 분석이며 법률자문이나 투자 권유가 아닙니다.

## 1. 법적 상태 (기준일 2026-11-18)

- 전자증권법·자본시장법 개정안은 2026년 1월 15일 국회 본회의를 통과한 것으로 보도됐습니다. 정무위원회는 2025년 11월 27일에 먼저 통과시켰습니다. (`LAW_PROMULGATED_NOT_EFFECTIVE` 추정, `SUPPORTED_INFERENCE`)
- 시행일은 자료마다 다릅니다. 1년 유예 또는 2027년 2월 시행이라는 보도가 있어서, 정확한 시행일은 **추가 검토 필요**입니다.
- 시행령 확정 여부와 장외거래소 사업자 선정 결과는 이번 검색에서 확인하지 못했습니다. (`UNVERIFIED`)
- 아래 수익원은 모두 이 제도가 시행된 이후의 **사업 기회**입니다. 현재 확정된 수익이 아닙니다.

## 2. 기관별 수익원 (`SUPPORTED_INFERENCE`)

| 기관 | 돈 버는 방식 |
|---|---|
| 증권사 (발행 주관) | 기초자산 발굴·구조화·발행 주선 수수료, 투자자 모집 수수료 |
| 증권사 (유통·중개) | 장외 유통 플랫폼 거래 수수료, 투자자 계좌·판매 수수료 |
| 증권사 (자기자본) | 직접 투자, 유동성 공급(시장조성), 보유 증권 운용수익 |
| 신탁사·자산운용사 | 신탁 보수, 자산관리·운용 보수, 임대료 분배 관리 |
| 은행 | 수탁·예치, 대출·담보 연계, 신탁 수수료, 대금 결제 서비스 |
| 거래소·인프라 사업자 (KDX·NXT 컨소시엄 등) | 거래·청산·결제·예탁 수수료, 시스템 이용료 |
| 평가·감정·법무·회계 | 기초자산 평가·감정, 법률·회계 자문 수수료 |

## 3. 왜 수익이 되나

- **소액 분할 판매:** 부동산, 음악 저작권, 미술품처럼 큰 자산을 잘게 나누면 새 투자자를 모을 수 있고, 발행 건수도 늘어납니다.
- **비용 절감:** 분산원장으로 발행과 결제 과정을 줄이면 운영비를 낮출 수 있습니다.
- **유통시장 창출:** 지금까지 거래가 어려웠던 자산에 장외 유통이 생기면 거래 수수료가 새 수익이 됩니다.
- **자산 전환:** 기존 수익증권과 투자계약증권을 토큰증권으로 바꾸면 기존 상품에서 나오던 수수료 위에 새 상품을 더할 수 있습니다.

## 4. 수익을 제약하는 요인

- **초기 수익성:** 시스템 구축, 심사, 투자자 보호 체계에 먼저 비용이 듭니다.
- **유통 유동성:** 거래가 얇으면 수수료 수익이 작고 시장조성 비용만 커집니다.
- **인프라 경쟁:** 컨소시엄이 둘로 갈려 있어서 사업자 선정과 수수료 구조에 따라 이익이 달라집니다.
- **프라이빗 체인 한계:** 한 분석에 따르면 한국 법상 분산원장은 무허가형 퍼블릭 체인과 다르며, 퍼블릭 크립토 생태계와의 연동은 제한적일 것으로 봅니다.
- **기초자산 품질:** 평가가 부실하면 투자자 보호와 평판 위험이 생깁니다.

## 5. 더 확인할 것

- 개정법 조문별 시행일, 시행령, 금융위원회 가이드라인
- 장외거래소 사업자 선정 결과와 수수료 체계
- 각 증권사의 실제 발행 계획과 수익 공시
