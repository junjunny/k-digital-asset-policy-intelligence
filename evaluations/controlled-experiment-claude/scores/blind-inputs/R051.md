# 이더리움 네트워크 분석 (공식 문서 중심)

**기준일**: 2026-11-18 · **유형**: 네트워크·프로토콜 검토 (STANDARD) · **한국 규제**: 질문에 없어 제외

**근거와 한계**
- 근거는 ethereum.org 공식 문서입니다. EIP 원문, GitHub, 클라이언트 저장소는 직접 대조하지 못했습니다.
- 따라서 아래 내용은 대부분 "공식 문서의 서술"입니다. 독립 검증을 마친 사실이 아닙니다.
- L2BEAT 조회는 시도했지만, 요청 도메인과 다른 도메인(ethbeat.org)으로 리다이렉트되어 따라가지 않았습니다. L2 보안 단계(Stage)와 TVS 같은 제3자 지표는 이번 분석에서 확인하지 못했습니다.
- 경쟁 네트워크는 이번에 공식 자료를 조회하지 않았습니다. 해당 절은 구조적 비교 틀만 제시합니다.

## 1. 구조: 실행 계층과 합의 계층

| 구분 | 역할 | 근거 |
|---|---|---|
| 실행 계층(EL) | 트랜잭션을 모아 실행하고 상태 변화를 만든 뒤 실행 페이로드를 생성합니다. | PoS 문서 |
| 합의 계층(CL) | 실행 페이로드를 비콘 블록으로 감싸고 증명(attestation)과 합의 데이터를 포함합니다. | PoS 문서 |
| 검증 | 다른 노드가 트랜잭션을 재실행해 블록을 검증합니다. | PoS 문서 |

- 검증자는 실행 클라이언트, 합의 클라이언트, 검증자 클라이언트 세 가지를 함께 운영합니다.
- 두 계층을 잇는 인터페이스(Engine API)는 이번에 조회한 페이지에 명시되지 않았습니다. 별도 문서 확인이 필요합니다.

## 2. PoS (확인된 공식 서술)

- **스테이킹**: 검증자는 32 ETH를 예치 컨트랙트에 넣고, 활성화 대기열이 신규 진입 속도를 제한합니다.
- **시간 단위**: 슬롯은 12초, 에포크는 32슬롯입니다. 슬롯마다 제안자 1명과 무작위 위원회가 선정됩니다.
- **최종성(Casper-FFG)**: 체크포인트가 총 스테이킹 ETH의 2/3 이상 득표하면 정당화되고, 이전 체크포인트가 최종 확정됩니다. 확정된 블록을 되돌리려면 총 스테이킹의 1/3 이상이 소각되어야 합니다.
- **비활동 누수**: 4에포크 넘게 최종성이 깨지면 다수결에 불참한 검증자의 스테이크가 줄어듭니다.
- **슬래싱**: 같은 슬롯에서 블록을 중복 제안하거나 모순된 증명을 내면 처벌받습니다. 규모는 동시 슬래싱된 검증자 수에 따라 소액부터 전액 손실까지 달라집니다.
- **이력**: 비콘체인은 2020-12-01에 시작했고, The Merge는 2022-09-15에 이뤄졌습니다. 에너지 사용은 약 99.95% 감소했다고 서술합니다. 이 수치는 문서 주장이며 독립 검증하지 않았습니다.

## 3. EVM과 계정

- EVM은 네트워크의 연산을 처리하는 구성요소이며, 가스는 연산 비용으로 ETH로 지불합니다.
- 계정은 개인키로 제어하는 EOA와 컨트랙트 계정으로 나뉩니다.
- L2 문서는 OP Mainnet을 "EVM-equivalent 옵티미스틱 롤업"으로 소개합니다. 이런 EVM 호환성이 개발자 생태계의 이식성 근거입니다.

## 4. 수수료 (EIP-1559 구조, 가스 문서)

- 총수수료는 `사용 가스 × (기본료 + 우선료)`입니다.
- 기본료는 직전 블록들로 산정하며 소각됩니다. 우선료(팁)는 검증자에게 갑니다.
- 블록 목표 크기는 가스 한도의 절반이고 최대는 목표의 2배입니다. 기본료는 블록당 최대 ±12.5% 조정됩니다.
- 단순 ETH 전송은 21,000 가스입니다.
- ETH 소개 페이지에는 전송 약 $0.0055, 스왑 $0.033~0.039, L2 전송 $0.01 미만이라는 수치가 있습니다. **기준일이 표기되지 않아** 현재 수수료의 근거로 쓰기 어렵습니다. 실시간 확인이 필요합니다.

## 5. L2와 확장

- 공식 문서는 메인넷 확장 방식을 롤업 중심으로 설명합니다. 메인체인 자체를 키우면 노드 요건이 높아져 탈중앙화가 약해지기 때문이며, 샤드 체인은 로드맵에서 제외됐습니다.
- 데이터를 이더리움에 게시하는 네트워크를 직접적인 확장(롤업)으로 보고, 그렇지 않은 네트워크는 독립 네트워크로 구분합니다.
- **공식 L2는 없고** 설계와 위험 프로파일이 서로 다릅니다. 안전성은 기술, 스마트컨트랙트 보안, 성숙도에 달려 있습니다.
- Dencun(2024-03-13)의 EIP-4844는 블롭 트랜잭션으로 롤업 데이터 비용을 낮췄습니다. Pectra(2025-05-07)는 블롭 처리량을 늘렸고, Fusaka(2025-12-03)는 PeerDAS를 도입했습니다.
- 참고: 조회한 L2 페이지에는 ZK 롤업 설명이 없었습니다. L2별 보안 단계와 실제 사용량은 **미확인**입니다.

## 6. 탈중앙화와 보안

**클라이언트 다양성** (ethereum.org, 2025-10 스냅샷):

| 계층 | 클라이언트별 점유율 |
|---|---|
| 실행 | Geth 41%, Nethermind 38%, Besu 16%, Erigon 3%, Reth 2% |
| 합의 | Lighthouse 42.7%, Prysm 30.9%, Teku 13.9%, Nimbus 8.7%, Lodestar 2.7%, Grandine 1.0% |

- 문서 기준 위험 임계값은 33%와 2/3입니다. 클라이언트 하나가 33%를 넘으면 버그가 최종성을 멈출 수 있습니다. 2/3를 넘으면 잘못된 체인이 확정되어 검증자가 슬래싱될 수 있습니다.
- 위 수치로는 실행·합의 클라이언트 모두 단일 클라이언트가 33%를 넘습니다. 문서 이상치(어떤 클라이언트도 33% 미만)와 다릅니다.
- 이 페이지에는 내부 불일치도 있습니다. 본문은 Geth가 약 85%이고 Prysm이 다수라고 쓰지만, 표 수치와 맞지 않습니다. 본문이 낡은 것으로 보이며, 현재값은 별도 확인이 필요합니다.
- 소비자 하드웨어로 노드를 운영할 수 있는지, 스테이킹 지분 집중도(스테이킹 풀, 거래소 비중)는 이번에 **확인하지 못했습니다**.

## 7. ETH의 역할 (ETH 페이지)

- **가스**: 네트워크와 앱 이용 수수료로 쓰입니다.
- **스테이킹 담보**: 네트워크 보안의 기반입니다.
- **발행과 소각**: 검증자 보상으로 발행되고 수수료 일부는 소각되어, 사용량에 따라 인플레이션과 디플레이션이 번갈아 나타납니다.
- **담보 자산**: DeFi 담보로는 네이티브 ETH가 아니라 WETH(ERC-20, 1:1)가 쓰인다고 서술합니다.
- 재단 보유량은 "0.3% 미만"으로 서술합니다.
- 가격과 투자 판단은 다루지 않습니다.

## 8. 업그레이드와 로드맵: 실제 구현 vs 계획

**구현 완료** (공식 이력 페이지 기준):

| 업그레이드 | 날짜 | 핵심 내용 |
|---|---|---|
| Paris (Merge) | 2022-09-15 | EIP-3675, PoW에서 PoS로 전환 |
| Shapella | 2023-04-12 | EIP-4895, 스테이킹 출금 활성화 |
| Dencun | 2024-03-13 | EIP-4844, 블롭 |
| Pectra | 2025-05-07 | EIP-7702, EIP-7251(최대 유효잔고 2048 ETH), 블롭 증가 |
| Fusaka | 2025-12-03 | PeerDAS, 가스 한도·DoS 하드닝 (이력 페이지는 EIP 목록 미기재) |

**계획 (미실현)**:
- **Glamsterdam**: 로드맵은 2026년 4분기로 서술하고 enshrined PBS와 블록 수준 접근 목록을 담는다고 합니다. 반면 이력 페이지는 일정을 TBD로 둡니다. **페이지 간 불일치**이므로 오늘(2026-11-18) 기준 활성화 여부는 확인되지 않았습니다.
- **Hegotá**: 2027년으로 서술하며 포크 선택 강제 포함 목록과 frame transaction을 담습니다. 범위가 확정되지 않았다고 명시합니다.
- **연구·미래 과제** (일정 없음): 양자 내성, 단일 슬롯 최종성, zkEVM, 무상태성(statelessness), 완전한 Danksharding, 기본 프라이버시.

## 9. 계정 추상화

| 항목 | 상태 | 비고 |
|---|---|---|
| ERC-4337 | **구현·운영 중** | 프로토콜 변경 없이 UserOperation으로 동작합니다. EntryPoint는 2023-03-01 메인넷에 배포됐습니다. 문서는 스마트 월렛 2,600만 개 이상, UserOperation 1억 7천만 건 이상이라고 서술하지만 집계 기준일은 확인하지 못했습니다. |
| EIP-7702 | **Pectra로 활성화** (이력 페이지 기준) | EOA가 스마트컨트랙트 코드처럼 동작합니다. AA 페이지는 아직 "예정"이라고 적어 낡은 서술로 보입니다. |
| 프로토콜 내재 AA | **연구·계획** | 로드맵 페이지는 계정 추상화를 장기 과제에 포함합니다. |

- 문서가 설명하는 이점은 맞춤 보안 규칙, 백업키 복구, 트랜잭션 묶음 처리, 수수료 대납과 ETH 외 토큰 지불입니다. 이는 설계 목적에 대한 서술이며 실제 채택률이나 보안은 별도 검증이 필요합니다.

## 10. 실제 사용·개발자 생태계·경쟁 네트워크

- **개발자 생태계**: 공식 문서는 Solidity 등 언어, 테스트·배포·검증 도구, 토큰 표준(ERC-20, ERC-721, ERC-1155), 오라클, MEV, 브리지를 다룹니다. 실제 개발자 수와 TVL은 이번에 **미확인**입니다.
- **경쟁 네트워크**: 공식 근거를 조회하지 않았으므로 결론은 내지 않습니다. 비교는 합의 방식, 검증자 요건, 최종성 시간, 확장 방식(L1 직접 확장과 롤업 분리), 장애 이력, 생태계 규모, 토큰 가치 포착 방식으로 하는 것이 좋습니다. 명목 TPS나 시가총액만으로 비교하지 않는 것이 이 스킬의 원칙입니다.

## 11. 한계와 다음 조사

1. EIP 원문(eips.ethereum.org)과 execution-specs, consensus-specs로 Fusaka·Glamsterdam 범위를 확인합니다.
2. 클라이언트 점유율과 스테이킹 집중도의 현재값을 ethernodes.org, clientdiversity.org 등에서 확인합니다.
3. L2별 보안 단계와 업그레이드·탈출 권한을 확인합니다. L2BEAT 직접 접속이 필요합니다.
4. 수수료와 사용량을 기준일이 있는 온체인 데이터로 확인합니다.
5. 경쟁 네트워크는 각 공식 문서로 같은 기준 비교표를 만듭니다.

이 내용은 정보 제공이며 투자 권유나 법률 자문이 아닙니다.
