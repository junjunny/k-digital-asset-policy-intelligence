# 체인링크(Chainlink, LINK)

**한 줄 요약:** 블록체인 스마트컨트랙트에 외부(오프체인) 데이터를 안전하게 전달하는 탈중앙화 오라클 네트워크의 토큰입니다.

이번 답변은 공식 문서를 새로 확인하지 않고 일반 지식으로 작성했습니다. 시세, 유통량, 스테이킹 조건 같은 최신 수치는 검증하지 않았습니다.

## 왜 필요한가
스마트컨트랙트는 블록체인 밖의 정보(가격, 날씨, 이벤트 결과 등)를 직접 알 수 없습니다. 이 문제를 오라클 문제라고 합니다. 한 곳에서 데이터를 가져오면 그 지점이 조작되거나 고장 날 위험이 있습니다. 체인링크는 여러 독립 노드가 데이터를 모아 합의하는 방식으로 이 위험을 줄입니다.

## 주요 서비스
- **Data Feeds:** 가격 등 시장 데이터를 제공합니다. 디파이(대출·DEX·파생상품)에서 가장 많이 쓰입니다.
- **VRF:** 검증 가능한 난수를 제공합니다. 게임과 NFT 추첨 등에 쓰입니다.
- **Automation:** 조건이 충족되면 컨트랙트를 자동 실행합니다.
- **CCIP:** 체인 간 메시지와 토큰 전송을 처리하는 상호운용 프로토콜입니다.
- **Proof of Reserve:** 스테이블코인과 토큰화 자산의 준비금을 검증합니다.
- **Functions / Data Streams:** 외부 API 연동과 저지연 데이터를 제공합니다.

## LINK 토큰
- 이더리움 기반 토큰(ERC-677)이고, 총 공급량은 10억 개로 알려져 있습니다.
- 노드 운영자에게 서비스 대가를 지급하는 데 쓰입니다.
- 스테이킹으로 노드의 신뢰성을 담보하는 구조가 도입되었습니다.
- 2017년 ICO로 출발했고, 공동창업자로 세르게이 나자로프가 알려져 있습니다. 운영 주체는 Chainlink Labs입니다.

## 알아둘 위험
- 오라클은 장애나 조작이 생기면 연결된 프로토콜 전체에 피해가 퍼질 수 있는 의존 지점입니다.
- 노드 운영과 업그레이드 권한이 얼마나 탈중앙화되어 있는지는 별도로 확인해야 합니다.
- 팀과 재단 보유 물량, 토큰 배분·해제 구조를 확인해야 합니다.
- Pyth, API3, RedStone 같은 경쟁 오라클이 있습니다.
- LINK의 가치가 실제 서비스 사용량과 얼마나 연결되는지는 불확실합니다. 수수료를 LINK 외 토큰으로 받는 경우도 있습니다.
- 국가별 규제 분류는 제가 확인하지 못했습니다.

이 내용은 투자 권유가 아니며 구조를 설명한 것입니다.
