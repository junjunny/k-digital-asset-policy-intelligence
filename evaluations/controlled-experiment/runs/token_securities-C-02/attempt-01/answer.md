금융기관은 토큰 자체의 가격 상승보다, 토큰증권의 **발행→판매→거래→보관·관리** 과정에서 반복적으로 수수료를 받는 방식으로 돈을 법니다.

| 단계 | 금융기관의 수익 |
|---|---|
| 상품 설계 | 기초자산 실사·증권 구조화·법률·공시 자문 수수료 |
| 발행·판매 | 인수·주선 수수료, 투자자 모집·판매 수수료 |
| 계좌·원장 관리 | 계좌관리, 명부·권리변동 관리, 시스템 이용료 |
| 거래 | 매매중개 수수료, 허용되는 경우 시장조성 스프레드 |
| 자산 관리 | 신탁·수탁·기초자산 관리보수 |
| 결제·자금 관리 | 결제계좌, 예치금·현금관리, 환전 관련 수익 |
| 사후 관리 | 배당·이자·임대수익 배분, 세무·공시·권리행사 대행료 |
| 인프라 제공 | 다른 금융회사·발행인에게 분산원장, API, 규제보고 시스템을 제공하는 B2B 이용료 |

업권별로 보면 다음과 같습니다.

- **증권사**: 발행 주선·인수, 투자자 판매, 장외거래 중개 수수료가 핵심입니다. 고객이 계속 거래하면 반복 수익이 생깁니다.
- **은행**: 결제계좌와 현금관리, 신탁·수탁, 기초자산 금융에서 수익을 얻을 가능성이 큽니다. 다만 증권 중개는 해당 인가가 필요합니다.
- **신탁사·자산운용사**: 부동산·채권·미술품 같은 자산을 신탁이나 펀드로 묶어 운용보수를 받습니다.
- **거래·인프라 사업자**: 거래 체결, 계좌·원장 관리, 공시·본인확인 시스템의 이용료를 받습니다.

가장 매력적인 모델은 일회성 발행수수료 하나가 아니라 다음 조합입니다.

> **수익 = 발행액 × 발행수수료 + 거래대금 × 중개수수료 + 관리잔액 × 연간 관리보수**

예를 들어 부동산을 토큰증권으로 발행하면 증권사는 처음에 구조화·판매 수수료를 받고, 이후 거래가 발생할 때 중개수수료를 받으며, 신탁사는 임대료 배분과 자산관리 보수를 계속 받을 수 있습니다. 이는 제도에서 확정한 수수료표가 아니라, 허용된 업무 구조로부터 도출되는 사업모델입니다.

다만 “토큰화하면 자동으로 큰돈을 번다”는 것은 아닙니다. 소규모 자산은 실사·공시·보안·AML·시스템 유지비가 수수료보다 클 수 있고, 2차 거래가 활발하지 않으면 거래수수료도 거의 없습니다. 결국 수익성을 좌우하는 것은 블록체인보다 **양질의 기초자산, 발행 규모, 거래량, 반복 발행 고객**입니다.

한국에서는 개정 전자증권법이 2026년 2월 3일 공포됐지만 **2027년 2월 4일 시행 예정**입니다.[E1: 확인된 사실, [국가법령정보센터](https://www.law.go.kr/lsInfoP.do?lsiSeq=283195&viewCls=lsRvsDocInfoR)] 금융위는 기존 인가 범위에서 증권사·장외거래소가 토큰증권을 취급하는 구조와 주식·채권·펀드까지 단계적으로 토큰화하는 방향을 제시했습니다.[E2: 확인된 사실, [금융위원회 정책방향](https://www.fsc.go.kr/no010101/87650)] 다만 발행인 계좌관리기관 요건과 장외거래소 거래한도 등은 2026년 10월 공개된 **하위법규 입법예고안** 기준이며 아직 확정 규정과 구분해야 합니다.[E3: 확인된 사실, [금융위원회 입법예고](https://www.fsc.go.kr/no010101/87838)]
