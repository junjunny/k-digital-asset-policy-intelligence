체인링크(Chainlink)는 **블록체인과 현실 세계의 데이터를 연결하는 탈중앙화 오라클 네트워크**이며, **LINK**는 이 네트워크에서 쓰이는 토큰입니다.

블록체인 자체는 외부 정보를 직접 확인하기 어렵습니다. 체인링크는 다음과 같은 정보를 스마트 계약에 전달합니다.

- 암호화폐·주식 등의 가격
- 날씨와 스포츠 경기 결과
- 준비금 증명
- 다른 블록체인에서 발생한 데이터

예를 들어 디파이 대출 서비스는 체인링크의 가격 정보를 이용해 담보가 부족한지 판단할 수 있습니다. LINK는 데이터 제공자에게 보상하거나 네트워크 보안을 위한 스테이킹 등에 사용됩니다.

핵심 특징은 **특정 블록체인 하나에 종속되지 않는 인프라형 프로젝트**라는 점입니다. 반면 LINK 가격은 네트워크 사용량과 반드시 비례하지 않을 수 있고, 경쟁 오라클·규제·토큰 유통량 등의 위험도 있습니다. 따라서 단순 결제용 코인보다는 **블록체인 데이터 인프라에 투자하는 성격의 토큰**에 가깝습니다.
