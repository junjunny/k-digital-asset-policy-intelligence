# K-DARI 프로젝트 제출용 요약

K-DARI는 일반 사용자의 디지털자산 질문을 12개 유형으로 분류하고, 질문에 맞는 공식 원문·법적 상태·기술 구현·사업모델 분석 절차를 적용하는 오픈소스 Agent Skill이다. 기존 모델을 재학습시키는 프로젝트가 아니라 호환 에이전트에 설치하는 분석 방법론 계층이다.

## 구현 근거

- 자연어 질문, 12개 라우팅 유형, 3개 답변 모드
- 공식 출처 접근·진위·발췌 일치·의미 검토의 단계 분리
- 법률안/현행법, 계획/구현, 파일럿/상용화 구분
- URL·리다이렉트·내부망·외부 파일 접근 방어
- EIB와 홍콩 디지털채권의 재현 가능한 사례와 근거 데이터
- GitHub 원격 fresh install 및 condition-blind 통제 실험

## 실측 결과

120개 생성·자동 평가·집계가 끝난 후 `evaluations/controlled-experiment/results/aggregate.json`의 계획/시도/성공/채점 수와 모든 유·불리한 대비를 이 절에 반영한다. 완료 전에는 실측 수치를 작성하지 않는다.

## 근거 검증 예시

CLARITY Act의 상원 기록에서 2026-09-15 표결은 법안 최종 통과가 아니라 H.R.3633 심의개시 동의에 관한 cloture였고 49–50으로 부결됐다. K-DARI는 이처럼 “법안 표결”이라는 요약을 표결 종류·버전·상태로 다시 분해한다.

Ethereum 계정 추상화는 EIP-4337 경로, EIP-7702 활성화 단계, 장래 native AA 목표를 구분한다. 문서·제안·배포·지갑 지원을 하나의 “구현 완료” 또는 “실험 단계”로 뭉뚱그리지 않는다.

## 한계

자동점수는 인간 승인이나 법률·기술 전문가 판단이 아니다. 검색 결과는 시점·도구·모델에 따라 변하고, 6개 주제와 조건별 30개 표본으로 보편적 성능을 주장하지 않는다. 네이버 외부 E군은 환경이 달라 인과 비교에 포함하지 않는다.
