# 지원서 2·3번 수정 후보

공고 URL은 자동 접근이 되지 않아 사용자가 제공한 공고 내용과 인계 문서 기준으로 작성했다. 각 본문은 1,000자 이내 초안이며 자동 제출하지 않는다. 통제 실험 최종 수치는 완료 후 확인된 값만 추가한다.

## 2번 후보 — Corporate 디지털자산 산업·정책 리서치

디지털자산 리서치에서 답변 품질이 사용자의 전문지식과 질문 설계 역량에 따라 크게 달라지는 문제를 발견했습니다. 이를 줄이기 위해 일반 질문에도 주제별 분석 방법론과 공식 원문 검증 절차를 적용하는 오픈소스 Agent Skill ‘K-DARI’를 개발했습니다. 법률·정책, 코인·프로젝트, 네트워크, 스테이블코인, RWA·토큰증권, 거래소 정책과 사업모델을 12개 유형으로 분류하고, 법률안과 현행법, 계획과 구현, 파일럿과 상용화를 구분하도록 설계했습니다. EIB와 홍콩 디지털채권 사례에서는 발행·원장·수탁·결제 가치사슬과 한국의 2027년 시행 예정 제도를 대조해 기회와 제약을 분리했습니다. 입사 후 1주차 연구범위 설정, 2주차 규제 타임라인, 3주차 고객·수익·가치사슬, 4주차 해외 기관 전략, 5주차 국내 도입 조건, 6주차 반대 사례 검증, 7주차 근거 점검 보고서, 8주차 공유·인계 순으로 매주 결과를 공유하겠습니다. 승인된 환경과 팀 동의를 전제로 개인 개발 경험을 팀의 재현 가능한 리서치 과정으로 확장하겠습니다.

## 3번 후보 — AI 연구·산업·정책 리서치

AX 혁신챌린지 대상과 AI 활용 개발 프로젝트를 수행하며 기술을 실제 문제 해결 과정으로 연결했습니다. 법무법인 해율 서포터즈에서는 복잡한 법률을 비전공자에게 설명했고, CEO저널 기자단에서는 기업의 AI 도입·교육 사례를 취재했습니다. 이 경험을 K-DARI 개발로 이어, 상세한 AI 답변과 신뢰할 수 있는 근거는 별개라는 문제를 통제 실험과 공식 원문 대조로 검증하고 있습니다. 네이버의 AI 브리핑·버티컬 에이전트·CLOVA Studio Skill 공개자료도 확인했으며, 기존 성과의 부재를 주장하기보다 디지털자산 분야의 상태 구분과 주장 단위 검증을 보완 연구하겠습니다. 입사 후 1주차 서비스·콘텐츠 파악, 2주차 모델 성능·추론비용·에이전트 조사, 3주차 글로벌 기업·오픈소스 전략, 4주차 안전·개인정보·저작권 정책, 5주차 내부 브리프, 6주차 승인 환경의 수집·요약·분류 자동화 비교, 7주차 활용 가치 콘텐츠, 8주차 결과 공유와 피드백을 수행하겠습니다. 장기적으로 분야별 분석 방법론을 AI 검색 품질 개선 연구로 확장하고 싶습니다.
