# 해외 금융기관·시장 인프라 토큰화 전략 비교

분석 기준일: 2026-11-18. 아래 내용은 기존 검증 사례의 공식 공개자료를 요약한 것이며 거래별 수익성·법률의견을 확정하지 않는다.

| 비교 | EIB £50m 디지털 채권 | 홍콩 다중통화 디지털 녹색채권 |
|---|---|---|
| 전략 형태 | 발행기관과 HSBC Orion의 직접 발행·인프라 결합 | 정부 발행, HSBC Orion, CMU와 국제 CSD 연결 |
| 고객 | 기관투자자, 주관·수탁기관 고객 | 글로벌 기관투자자 |
| 차별 가치 | private 법적 장부와 public mirror 분리 | 4개 통화와 기존 CMU·Euroclear·Clearstream 접근성 결합 |
| 운영 책임 | HSBC central account keeper, 기존 수탁기관 역할 유지 | 플랫폼과 CMU·계좌·수탁 구조 유지 |
| 가능한 수익원 | 주관·계좌관리·수탁·기술서비스 수수료 추론 | 발행·인프라 연결·수탁·결제·외환 서비스 수수료 추론 |
| 공개된 경제성 | 거래별 수수료·절감액 미확인 | 거래별 수수료·절감액·유동성 성과 미확인 |
| 상용성 판정 | 실제 발행 완료이나 플랫폼 전체 경제성은 미확인 | 실제 정부채 발행 완료이나 범용 상용 확장성은 미확인 |

두 사례 모두 “탈중개”보다 규제된 기관과 기존 시장 인프라의 책임을 디지털 원장에 연결했다. EIB의 차별점은 법적 장부와 공개용 데이터 층의 분리이고, 홍콩의 차별점은 다중통화·국제 CSD 상호운용이다. 서로 다른 가치이므로 국내 기회도 동일한 결론으로 환원하면 안 된다.

한국에서는 개정 전자증권법이 2027-02-04 시행 예정이고 분석 기준일에는 시행 전이다. 따라서 초기 기회는 현행법상 가능한 준비·실증과 시행 후 제도 활용을 구분해야 한다.

- 증권사: 기관 사모채 발행 주관·계좌관리·유통·대사
- 은행·수탁기관: 원화 결제·수탁, 이후 외환·다중통화 연결 검토
- 핀테크: 원장-CSD 연결, 권리행사, 규제보고·감사 추적
- 시장 인프라: 총량관리, 결제완결성, 참가자 인증과 장애 복구

이는 `SUPPORTED_INFERENCE`다. 실제 기회가 되려면 최종 하위법규, 예탁원 규격, 기관 수요, 책임 배분, 기존 대비 비용·시간 데이터가 필요하다.
