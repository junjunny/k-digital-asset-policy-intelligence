# Master Plan

## 목표

한국 시장에 특화된 디지털자산 정책·사업 리서치 방법론을 설치 가능한 Agent Skill로 제공하고, 공식 근거를 추적할 수 있는 실제 사례로 검증한다.

## 단계

| Phase | 산출물 | 완료 기준 | 상태 |
|---|---|---|---|
| 0. Foundation | 아키텍처, 출처·근거 모델, 스킬 조사, 테스트 전략 | 실행 계획과 검증 방법 확정 | 완료 |
| 1. Core Skill | `SKILL.md`, references, templates, schemas | 규격 검증 및 예시 호출 가능 | 완료 |
| 2. Evidence Engine | 출처·보고서 검증기, 자동 테스트 | 날짜·법적 상태·근거 연결 오류 탐지 | 완료(기본 엔진) |
| 3. Real Case | EIB 디지털 채권 국문 보고서·영문 요약·근거 JSON | 공식 자료 기반 사례 1건 검증 | 완료 |
| 4. Open Source | 국·영문 README, 라이선스, 설치 안내, 공개 점검 | 제3자 설치·재현 가능 | 로컬 준비 완료, 공개 확인 대기 |
| 5. Quality Hardening | Evidence v2, 규제 claim 검증, 부정 테스트, 독립 사례, CI | 원문·인용 검증과 fresh install, 새 질문 재현 | 구현 완료, 최종 검증 기록 참조 |

## 품질 게이트

- 주요 법적 주장은 공식 1차 자료에 연결
- 공포일·시행일·조회일·분석 기준일 분리
- 정책·입법예고를 현행법으로 표현하지 않음
- `VERIFIED_FACT`와 `SUPPORTED_INFERENCE`에 Evidence ID 필수
- 자동 테스트와 수동 법률 검토의 한계를 별도 기록

## 후속 확장

- 스캔 PDF OCR과 표·각주 구조 인식
- 원문 스냅샷 보존 정책과 장기 해시 비교
- 국가별 규제 모듈과 API 커넥터
- 보고서 사례 추가 및 전문가 검토 기록
