# Master Plan

## 목표

K-DAPI는 일반 사용자가 자연어로 질문하는 다양한 디지털자산 주제를 공식 근거로 분석하고, 관련성이 있을 때 한국의 법률·규제·정책·시장 환경과 연결하여 한국인에게 맞춤형 인사이트를 제공하는 범용 Agent Skill을 목표로 한다.

최종 사용자는 `npx skills add`로 설치한 뒤 지원 AI 에이전트에 자연어로 질문한다. 스킬은 질문 유형과 깊이를 판별하고 적절한 방법론을 선택하여 해외·국내 공식 자료를 확인하며, 검증된 사실·근거 있는 추론·미확인 사항을 구분한다. PDF 업로드와 외부 API 키는 필수 조건이 아니다.

## 지원 연구 유형

- 해외 디지털자산 법률 및 규제
- 한국 디지털자산 법률 및 정책
- 가상자산 프로젝트 및 백서
- 스테이블코인과 결제
- RWA 및 토큰증권
- 거래소 거래지원 정책
- 디지털자산 관련 사업모델

질문별 분석 프레임워크를 분리하며, 모든 질문을 토큰증권으로 유도하지 않는다. 한국과 실질적 연결이 없으면 억지로 만들지 않는다. 간단한 질문에는 간결하게, 심층 요청에는 구조화 보고서로 답한다. 웹 검색이 불가능하면 최신 검증 불가를 명시한다.

## 단계

| Phase | 산출물 | 완료 기준 | 상태 |
|---|---|---|---|
| 0. Foundation | 아키텍처, 출처·근거 모델, 스킬 조사, 테스트 전략 | 실행 계획과 검증 방법 확정 | 완료 |
| 1. Core Skill | `SKILL.md`, references, templates, schemas | 규격 검증 및 예시 호출 가능 | 완료 |
| 2. Evidence Engine | 출처·보고서 검증기, 자동 테스트 | 날짜·법적 상태·근거 연결 오류 탐지 | 완료(기본 엔진) |
| 3. Real Case | EIB 디지털 채권 국문 보고서·영문 요약·근거 JSON | 공식 자료 기반 사례 1건 검증 | 완료 |
| 4. Open Source | 국·영문 README, 라이선스, 설치 안내, 공개 점검 | 제3자 설치·재현 가능 | 로컬 준비 완료, 공개 확인 대기 |
| 5. Quality Hardening | Evidence v2, 규제 claim 검증, 부정 테스트, 독립 사례, CI | 원문·인용 검증과 fresh install, 새 질문 재현 | 구현 완료, 최종 검증 기록 참조 |
| 6. Human Review Gate | 검증 격차 보완, 사례 품질감사, 인간 검토 패키지, Phase 7 설계 | 자동 검증과 인간 판단의 경계 및 사용자 결정사항 명시 | 구현 완료, 사용자 검토 대기 |
| 7. Independent Natural-language Evaluation | 격리 설치본에서 미사용 자연어 질문을 처음부터 실행·평가 | 입력부터 출처 탐색·보고서 생성까지 독립 재현 및 인간 평가 | 사용자 승인 전 시작 금지 |

## 품질 게이트

- 주요 법적 주장은 공식 1차 자료에 연결
- 공포일·시행일·조회일·분석 기준일 분리
- 정책·입법예고를 현행법으로 표현하지 않음
- `VERIFIED_FACT`와 `SUPPORTED_INFERENCE`에 Evidence ID 필수
- 자동 테스트와 수동 법률 검토의 한계를 별도 기록
- 출처 진위·문서 접근·발췌 일치·법률적 의미 검토를 별도 상태로 기록
- 질문 유형별 방법론을 적용하고 무관한 한국 규제 연결을 만들지 않음
- 저장된 사례 검증과 실제 자연어 E2E를 구분

## Phase 7 독립 테스트 원칙

상세 범위는 `docs/PHASE_7_TEST_PLAN.md`에 둔다. 필수 입력은 “미국 CLARITY Act를 분석하고 한국 디지털자산 규제와 비교해 줘.”이다. 테스트 실행 시점에 미국 의회 공식 원문과 법안 진행상태, 한국 공식 법령·정책의 최신 상태를 새로 조회해야 하며, 현재 저장된 지식으로 상태를 가정하지 않는다. 기존 EIB·홍콩 산출물이나 정답 문장을 재사용하지 않고 격리 설치 환경에서 자연어 입력부터 결과 생성까지 평가한다. Phase 7은 사용자 승인 후에만 시작한다.

## 후속 확장

- 스캔 PDF OCR과 표·각주 구조 인식
- 원문 스냅샷 보존 정책과 장기 해시 비교
- 국가별 규제 모듈과 API 커넥터
- 보고서 사례 추가 및 전문가 검토 기록
