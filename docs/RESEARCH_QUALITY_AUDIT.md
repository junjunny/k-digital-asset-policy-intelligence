# Research Quality Audit

기준일: 2026-11-16

## 평가 척도

- **충족**: 공식 원문과 보고서 표현이 직접 대응하고 중요한 반론·한계가 명시됨
- **부분 충족**: 핵심 방향은 근거가 있으나 발췌 범위, 적용 법규, 독립 자료 또는 구체성이 부족함
- **미충족**: 근거가 없거나 법적 상태·사실·추론을 혼동함
- **사람 검토 필요**: 자동 검증으로 결론을 낼 수 없음

## 항목별 평가 기준

| 항목 | 충족 기준 |
|---|---|
| 사실 정확성 | 금액·날짜·행위자·구조가 주장 단위의 원문과 일치하고 상충 자료가 없음 |
| 출처 신뢰도 | 발행기관·법령·감독기관 1차 자료이며 진위·버전·조회일을 확인함 |
| 규제 해석 정확성 | 관할권·적용대상·법적 상태·시행일·예외·경과규정을 구분하고 개별 적용을 과장하지 않음 |
| 해외 사업모델 이해도 | 고객·가치·권리·원장·발행·유통·수탁·결제·수익·위험을 사례 고유 구조로 설명함 |
| 국내 적용 분석 깊이 | 한국의 실제 법령·정책·시장 인프라와 비교하며 불필요한 연결을 만들지 않음 |
| 사업적 시사점 구체성 | 행위자·고객·수익원·비용·실행조건·선행조건과 측정 가능한 검증방법을 제시함 |
| 반론·불확실성 반영 | 대체 설명, 실패 조건, 비공개 자료, 데이터 부족, 규제 변경 가능성을 명시함 |

## EIB Digital Bond 감사

| 항목 | 평가 | 감사 결과 |
|---|---|---|
| 사실 정확성 | 부분 충족 | EIB 공식 발표와 발행일·원장 구조 방향은 연결된다. 다만 구조화 Evidence의 한 문장 발췌가 £50m, private/public 원장, central account keeper, 수탁사 등 하나의 finding에 묶인 모든 세부 사실을 각각 증명하지는 않는다. 주장별 발췌가 필요하다. |

| 규제 해석 정확성 | 부분 충족 | DLT Pilot 적용일 이후·이전 구분과 한국 시행 예정법·입법예고 구분은 강점이다. EIB 거래에 직접 적용된 룩셈부르크 법령과 거래별 법률의견은 미확인이다. |
| 해외 사업모델 이해도 | 부분 충족 | 법적 원장과 공개 mirror, 규제기관·수탁기관의 지속 역할을 구분했다. 결제 구조, 투자자 흐름, 실제 수수료·운영성과는 자료 부족으로 설명이 제한된다. |
| 국내 적용 분석 깊이 | 부분 충족 | 기관 사모사채로 범위를 좁힌 점은 한국 정책과 정합적이다. 예탁원 연계·인가·책임 배분은 입법예고와 분석자 추론이며 최종 규칙·기술기준이 없다. |
| 사업적 시사점 구체성 | 부분 충족 | 발행·계좌관리·수탁·대사 도구의 역할을 제시한다. 고객 수요, 가격, 비용 절감, 수익 규모, 경쟁 대안은 검증되지 않았다. |
| 반론·불확실성 반영 | 부분 충족 | 법 시행 전, 경제성 미확인, 법률의견 미공개를 밝혔다. 추가로 이중 원장 복잡성, 공개 mirror의 실익, 벤더 종속, 기존 전자증권 대비 증분 가치가 필요하다. |

| 규제 해석 정확성 | 부분 충족 | 기존 증권규제와 기술위험의 병행, Expert Group의 정책 성격을 구분했다. 개별 채권에 적용된 홍콩 법령·면제·법률의견은 미확인이다. |
| 해외 사업모델 이해도 | 부분 충족 | 다중통화, 중앙 인프라, 국제 연결이라는 사례 고유 가치를 포착했다. 현금 결제, 외환, 녹색채권 검증, 비용·유동성 성과는 충분히 설명되지 않는다. |
| 국내 적용 분석 깊이 | 부분 충족 | 다중통화를 후속 단계로 분리한 보수적 분석은 타당하다. 국내 외국환·지급결제·해외투자자 접근의 구체 법적 경로는 조사하지 않았다. |
| 사업적 시사점 구체성 | 부분 충족 | 기관 원화채권, 수탁, 원장-CSD 연결 역할을 제시한다. 홍콩 고유의 다중통화·국제 유통 가치가 한국에서 어떤 고객과 매출로 이어지는지는 미검증이다. |
| 반론·불확실성 반영 | 부분 충족 | 외국환·세무·회계·녹색 인증과 비용효과 한계를 밝혔다. 추가로 국제 CSD 연결의 비용, 유동성 개선 여부, 사이버·집중 위험, 녹색성의 독립 검증이 필요하다. |

## 사례 간 비교

두 보고서는 서로 다른 해외 가치를 식별한다. EIB는 private legal record와 public mirror의 역할 분리, 홍콩은 다중통화와 CMU·국제 CSD 연결이 중심이다. 그러나 한국 부분은 같은 시행 예정법·정책·입법예고를 사용하여 “기관 원화 사모사채 + 허가형 원장 + 기존 결제”라는 결론으로 수렴한다. 이는 초기 제도 범위의 공통 제약을 반영하지만, 사업 기회 목록도 유사해 사례 고유의 국내 가치가 약해졌다.

홍콩 사례는 외국환·국제 유통·다중통화 수요가 입증될 때 EIB와 다른 국내 기회로 발전할 수 있다. EIB 사례는 공개 mirror의 규제보고·감사 활용 가치가 입증될 때 차별화될 수 있다. 현재 자료만으로 어느 기회도 사업성이 확인됐다고 말할 수 없다.

## 공통 반론

- 토큰화가 기존 중앙 원장보다 비용·속도·유동성을 실제로 개선하지 못할 수 있다.
- 기존 CSD·수탁·현금결제를 그대로 유지하면 기술 계층만 늘어날 수 있다.
- 플랫폼 집중, 키 관리, 사이버 사고, 원장 불일치가 새 운영위험을 만든다.
- 정책의 우선 검토 대상이 실제 허용·인가 또는 고객 수요를 의미하지 않는다.
- 해외 정부·국제기관 거래의 신용과 규모를 민간 한국 사업에 그대로 일반화할 수 없다.

## 자동 검증과 인간 검토의 경계

현재 도구는 파일 구조, 날짜 논리, claim type과 legal status의 구조적 호환성, 문서 접근, 발췌 문자열 일치를 점검한다. 출처의 실질적 진위, 발췌의 전체 문맥, 법률 해석, 주장의 의미상 충분성, 사업성은 사람이 판단해야 한다. 검증기 경고는 이 한계를 명시하며, 통과 결과를 법적 결론으로 사용하지 않는다.
